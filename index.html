media-stack-archive

A personal tool. Not a product, and not available to anyone else.

media-stack-archive is a single-user utility that keeps an encrypted backup of one private personal media collection in its operator's own Google Drive account. The collection is private, is not shared with anyone, and is not published, streamed or distributed beyond the household that owns it. The tool is built on rclone and runs on one private machine.

What it does

  • Uploads files from a private media library to one folder in the operator's own Google Drive.
  • Encrypts every file before it leaves the machine, so the stored data is unreadable without a key that never leaves that machine.
  • Reads those files back when the operator plays them.
  • Deletes them when the operator removes them from the library.

Who can use it

Nobody else. There is no sign-up, no hosted service and no shared instance. The OAuth client exists only so that one person's copy of rclone can reach one person's own Drive.

Google account access

It requests access to the operator's own Google Drive in order to upload, download and delete the operator's own files. It never accesses anyone else's account, and it sends nothing to any third party. The details are in the privacy policy.
