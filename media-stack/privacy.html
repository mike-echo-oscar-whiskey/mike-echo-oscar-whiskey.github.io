Privacy policy

media-stack · last updated 29 September 2026

media-stack is a personal, single-user tool built on rclone. It backs up one private personal media collection — backup copies of physical discs the operator owns — to the operator's own Google Drive. It runs on one private machine and connects only to the Google account of the person operating it. There are no other users, no hosted service, no sharing or distribution of any kind, and no servers operated by the author beyond that one machine.

What Google account data it accesses

The OAuth client requests these scopes:

  • https://www.googleapis.com/auth/drive — to create, read, rename and delete the operator's own files inside a single folder of the operator's own Google Drive. This is the scope that lets the tool upload files to that folder, read them back for playback, and remove them when the operator deletes them.
  • https://www.googleapis.com/auth/drive.metadata.readonly — to list the folder and read file names, sizes and modification times, so the tool can tell what is already stored without downloading it.
  • https://www.googleapis.com/auth/docs — required by rclone alongside the Drive scope above. The tool stores and retrieves ordinary binary files and does not create, read or modify Google Docs, Sheets or Slides.

Access is further restricted to a single folder using rclone's root_folder_id setting, so the token cannot reach the rest of the Drive.

What happens to the data

  • Files are encrypted before they leave the machine. The tool uses rclone's crypt layer (XSalsa20-Poly1305, with the key derived from a passphrase held only on the operator's machine). What is stored in Google Drive is ciphertext.
  • It is never shared, sold or transferred. No data is sent to the author, to any analytics service, or to any third party. The only network destinations are Google's own APIs and the operator's machine.
  • Nothing is retained elsewhere. The tool keeps no copy of the operator's Google data outside their own Drive and their own machine.
  • No human reads it. There is no support team and no operational access; the content is unreadable without the passphrase in any case.

Credentials

The OAuth refresh token issued by Google is stored in rclone's configuration file on the operator's own machine, with file permissions restricting it to that user account. It is not transmitted anywhere other than to Google when refreshing access.

Revoking access

Access can be withdrawn at any time from Google Account → Third-party apps & services. Doing so immediately stops the tool from reaching the Drive. Files already stored remain in the Drive folder and can be deleted there like any other file.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
